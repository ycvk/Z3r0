# Aegis Workspace

This directory holds durable design, planning, and baseline records for Z3r0.

- `specs/` — approved or in-review design/spec artifacts
- `plans/` — implementation plans derived from specs
- `baseline/` — snapshots of product and architecture truth
- `adr/` — architecture decision records after a decision is executed
- `INDEX.md` — catalog of workspace documents
- `BASELINE-GOVERNANCE.md` — how requirement truth and architecture truth are kept distinct
